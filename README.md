# Material suplementar do TCC

**Análise do Uso de Modelos de Linguagem de Grande Escala na Extração e Especificação de Requisitos a partir de Histórias de Usuário**

Gabriel Romero e Franciene Duarte Gomes
Universidade Federal de Mato Grosso do Sul (UFMS), Campus de Três Lagoas (CPTL), Sistemas de Informação, 2026.

Este repositório reúne os apêndices e os dados de análise do trabalho, para permitir a conferência e a reprodução dos resultados.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| `Apendice_A_Especificacao_de_Referencia.pdf` | Especificação de referência com 48 elementos (RF, RNF, RN e RST) elaborada para as dez histórias de usuário e avaliada por especialista. |
| `Apendice_B_Prompt_e_Respostas.pdf` | Prompt padronizado e respostas integrais do ChatGPT e do Claude para as dez histórias, com data e horário de cada execução. |
| `Planilha_de_Analise.xlsx` | Mapeamento de cada modelo contra a referência, elementos sem correspondência direta, avaliação de qualidade (corretude, completude, não ambiguidade e verificabilidade) e resultados consolidados. |

## Execução dos experimentos

- Modelos: ChatGPT (GPT-5.6 Luna) e Claude (Claude Sonnet 5.5), pelas interfaces web, com configurações padrão.
- Período: 21 e 22 de setembro de 2026.
- Entradas: 10 histórias de usuário em inglês; saídas em português.
- Uma execução por história em cada modelo, em sessão independente.

## Fonte das histórias de usuário

As histórias de usuário pertencem ao conjunto de dados de Dalpiaz, Sturm e Gieske (2020), subconjunto do sistema hospitalar (HOS), distribuído sob licença CC BY 4.0:

DALPIAZ, Fabiano; STURM, Arnon; GIESKE, Patrizia. Extraction of conceptual models: user stories vs. use cases. [S. l.]: Zenodo, 2020. DOI: 10.5281/zenodo.4121935.
